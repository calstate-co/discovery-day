# Stage 4 - Publish

## Purpose and milestone

Purpose: turn the approved preview into a recurring task the attendee controls.

Milestone: the attendee explicitly confirms activation, the task is created or enabled successfully, and the final configuration is handed back to them.

## Present the publication summary

Start with the stage label **Adventure B - Stage 4 of 4: Publish**. Before any activation, show a concise final summary:

- task name;
- run day, time, recurrence, and timezone;
- workweek window;
- vacation or out-of-office skip rule;
- selected sources and scope;
- Weekly Preparation Planner output;
- delivery behavior;
- read-only boundaries;
- any unavailable capability or known limitation; and
- what the attendee can edit later.

Resolve material ambiguities before continuing.

## Require explicit confirmation

Ask a direct question such as:

> Shall I create and activate this recurring task with the settings above?

Do not treat prior approval of the preview, enthusiasm, or permission to continue as activation permission. Wait for a clear yes.

If the attendee wants a saved but inactive task and the platform supports it, honor that choice. If the platform cannot separate creation from activation, explain the limitation before asking for confirmation.

## Create and verify

After confirmation:

1. create or update the recurring task using the attendee's personal timezone;
2. preserve the approved task prompt and Weekly Preparation Planner requirements;
3. enable it only as authorized;
4. inspect the returned task state and schedule; and
5. do not report success unless the operation succeeds.

If publication fails because an app must be connected or reauthorized, explain the blocker and pause. Do not weaken source requirements or silently publish a broader or narrower task.

## Delivery choices

The Weekly Preparation Planner can remain the primary result in ChatGPT. If the attendee requests an email draft, create a draft only after recipient resolution and keep it unsent. Be transparent if the email connector supports only plain text rather than rendered HTML. Automatic sending requires a separate explicit request and an available action. Do not imply that the output is a Microsoft Planner plan unless Microsoft Planner was explicitly requested and its capability was verified.

## Hand off

Tell the attendee:

- when the first run is expected;
- where the result or draft will appear;
- how to pause, edit, or disable the task;
- that source connections and permissions can affect future runs; and
- that the skill name and task configuration can be changed later.

When verified, announce that Stage 4 is complete, congratulate the attendee on finishing Adventure B, and direct them to the **4 Publish booth** to collect the Publish stamp on their Discovery Day stamp card. Remind them that the four core stamps qualify them for the raffle and that they may collect bonus stamps at the **Security, Privacy and Accessibility booth in Anacapa** and the **Use Case Exchange bonus booth**. Remind them to retain their take-home Weekly Preparation Planner.
