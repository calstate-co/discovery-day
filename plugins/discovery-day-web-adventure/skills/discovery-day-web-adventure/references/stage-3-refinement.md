# Stage 3 - Refine

## Purpose and milestone

Purpose: use direct feedback on the rendered private Sites preview to make the site feel intentional, useful, and ready to publish internally.

Milestone: the attendee has either left and resolved browser annotations or explicitly approved the site as-is, then reviewed the updated workspace-private page.

## Review in the browser

Use the stage label **Adventure A - Stage 3 of 4: Refine**. Keep the attendee's own workspace-private Sites preview open in the built-in browser side panel. If you need to provide the URL again, label it **Open in the ChatGPT side panel** and provide it as copyable text; each attendee's site has its own URL.

Ask the attendee to review the page for clarity, content, visual hierarchy, spacing, readability, mobile behavior, accessibility, and whether the primary action is obvious.

When browser annotations are available, guide them precisely:

1. Explain that an annotation is a comment attached to a specific part of the page.
2. Remind the attendee that annotation controls are available only in the ChatGPT app's side panel, not in a regular web browser.
3. Turn on annotation mode in the built-in browser.
4. Click an element or drag across the part of the page they want to change.
5. Write a specific comment describing the problem and desired result, then save it.
6. Repeat for other focused changes.
7. Return to chat and ask ChatGPT to address the saved browser comments.

After changes are made, update the attendee's existing private Sites preview, then reopen or refresh it in the side browser and inspect the rendered result. Keep the scope narrow: one review pass can contain multiple focused comments, but do not turn late feedback into a new application.

If annotation mode is unavailable, collect the same feedback in chat with section names and clear desired outcomes. Never say an annotation was saved or addressed without verification.

## Stage close

Summarize the annotations or feedback, what changed, what was verified, and any remaining limitation. Ask the attendee to approve the finished page. State whether the refinement milestone is complete, and ask whether the attendee wants to continue unless they have already clearly asked to proceed. When approved, announce Stage 3 complete and direct the attendee to the **3 Refine booth** to collect the Refine stamp. Explain that the four core stamps qualify them for the raffle. For access or troubleshooting, direct them to the **IT Support booth in Anacapa**.
